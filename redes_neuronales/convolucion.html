¿Qué está pasando matemáticamente?

La convolución es una operación donde una ventana pequeña (el kernel de 3x3) se desliza por toda la imagen. En cada paso, se multiplica elemento a elemento el valor de los píxeles de la imagen por los pesos del kernel, y luego se suman todos esos resultados para generar un nuevo píxel en la imagen resultante.

Nuevo Píxel = Σ (Píxel_Vecino × Peso_Kernel)

Este es el fundamento de las Redes Neuronales Convolucionales (CNNs). La red aprende a ajustar automáticamente los números del kernel para extraer bordes, texturas o patrones complejos útiles para clasificar imágenes.
